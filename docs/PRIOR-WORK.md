# Prior work statement

The small-business insurance engine in VERIS derives from an earlier prototype created and owned by this team. This repository restructures that work into an evidence-bound household and small-business insurance assistant with explicit jurisdiction data, encrypted tenant storage, deterministic claim tooling, and local synthetic counterparty evidence.

No external organisation, event, customer, insurer, bank, or provider endorses this repository. Human contributors must complete the separate attribution and reuse-confirmation actions recorded in `07-fintechathon/human-actions.md` before any public release.
